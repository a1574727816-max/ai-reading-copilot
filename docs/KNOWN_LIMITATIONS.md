# 已知限制

1. 自动化运行环境为 Linux Chromium。原生侧边栏的浏览器工具栏入口、系统右键菜单与 Windows Chrome/Edge 的最终手动安装体验需在实际设备复核；网页提取、UI、模型协议与消息链路已有真实扩展自动化测试。
2. 宇树指定 URL 在本测试环境返回 `Access Restricted`。扩展会报告访问受限，不声称读到 Go2 正文。需要用户浏览器中正常加载后的实际页面验证，不绕过验证或站点安全边界。
3. 庐山派指定入口的产品介绍主要在图片中，当前只能读取少量 DOM 文字。会标注部分内容及图片未识别；应在下级文字教程使用问答功能。OCR、图片、电路原理图理解属于后续版本。
4. 仅针对当前网页，不自动读取同站其他章节、跨域 iframe 或 Shadow DOM 内文档。无限滚动/虚拟列表只覆盖当前 DOM 中已加载的内容，不自动滚动抓取。
5. 正文解析是通用启发式方案，特殊站点仍可能需要增加根容器与噪声规则；无法稳定定位引用时返回失败，不跳到未经校验的段落。
6. API 兼容层面向文本 Chat Completions 与常见 SSE。厂商专有参数、Responses API、工具调用、多模态内容、客户端证书、私有认证头尚未适配。温度不支持时可留空，模型列表不支持时可手填 ID。
7. Token 仅显示服务实际返回的数据。部分流式服务不返回 usage 时不猜测，也不提供真实费用账单。摘要过程的多次调用不显示成一个完整累计账单。
8. API Key 的本地保存不是加密保险箱；其他本机用户或恶意软件可能读取。默认使用浏览器会话保存，且不向 content script 暴露。
9. Prompt Injection 以权限隔离、只读边界、不可信内容标记和输出过滤降低风险；不能保证模型永不被恶意文档误导。密钥根本不进入模型上下文，模型不具有浏览器操作权限。真实引用仅证明片段存在，无法自动证明回答推理正确。
10. 为控制资源占用，单页文字提取上限 500,000 字符。达到上限时只分析已提取部分并明确提示；历史使用最近有限消息，不永久保留模型上下文中的全部对话。
11. 无后端和同步。卸载扩展、清理扩展数据、切换浏览器配置文件会使本地资料不可用。分享扩展 ZIP 不包含个人配置，朋友需要各自填写密钥。
