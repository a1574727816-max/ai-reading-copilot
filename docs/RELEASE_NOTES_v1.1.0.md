# AI Reading Copilot v1.1.0

默认交互改为“右键启用 → 读取当前文档 → 选中文字显示小浮窗”。

- 在网页空白处右键，点击“打开阅读助手”；启用后菜单变成“关闭阅读助手”，工具栏图标显示 ON。
- 启用时只在本地读取当前文档，不打开右侧栏，也不发送模型请求。选中文字后自动显示“解释概念 / 结合上下文 / 举例说明 / 向 AI 提问”。
- 解释在小浮窗内完成，并检索当前文档中的相关段落。首次发送确认和模型未配置提示也可在浮窗处理。
- 只有主动点击“向 AI 提问”或“详细解释 / 继续提问”才打开右侧问答栏。浮窗里的“关闭”只收起卡片。
- 再次右键关闭助手会停用当前页划词功能并取消正在生成的短解释。工具栏图标及 Alt+Shift+R 同样切换当前页开关。
- 不同标签页独立开启；刷新或跳转另一份文档后需重新开启。同页正文变化使旧缓存失效，下次解释使用新内容。

下载名称以 `extension.zip` 结尾的安装包，解压覆盖原来加载扩展的同一个文件夹，在 Chrome / Edge 扩展管理页点击“重新加载”，然后刷新文档网页。无需卸载，保留原目录可保留设置。若旧版右侧栏仍开着，点击其右上角关闭即可。

验证：24 项单元测试、TypeScript 检查、生产构建和 10 项 Chromium 端到端测试通过。原生入口测试在没有预授权网站权限的全新配置中执行真实右键菜单与工具栏动作，覆盖浮窗首次发送、关闭取消、文档检索及页面隔离。Windows Chrome / Edge 实机尚未复核。

发布包包含扩展 ZIP、源码 ZIP、SHA-256 校验文件及独立源码构建验证记录，不含个人 API Key。
