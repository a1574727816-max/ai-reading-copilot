# 工程方案与模块边界

采用 Manifest V3 + TypeScript + React + Vite。UI 使用 React 本地状态与共享 CSS 设计变量；选择浮层为轻量 DOM + Shadow DOM，避免把 React、Markdown 与数学渲染器注入普通网页。所有可执行代码随扩展打包。

| 模块 | 职责 | 边界 |
| --- | --- | --- |
| `src/content` | 选区、正文提取、浮层、定位、高亮、SPA 失效 | 无密钥、无模型地址配置读取，不接收网页 window 消息 |
| `src/background` | activeTab 注入、持续网站授权、右键与快捷键、Tab 消息路由、短解释请求 | 验证扩展来源与主框架，页面请求仅白名单处理 |
| `src/sidepanel` | 阅读状态、会话、上下文模式、检索与摘要编排、长时间流式请求 | 页面切换取消请求，以文档版本恢复对应会话 |
| `src/options` | 服务配置、权限、阅读偏好、数据清理 | 用户点击才申请服务域名权限；密钥输入默认遮蔽 |
| `src/services/llm` | Provider 接口、兼容格式、SSE、取消、超时与错误归类 | 不硬编码业务模型，不把服务错误原文或密钥写日志 |
| `src/services/retrieval` | 中英文分词、BM25、邻近块、预算与摘要分批 | 不需要向量服务，无额外后端 |
| `src/services/context` | 系统提示、不可信原文分隔、历史裁剪、引用 ID 约束 | 模型无法调用浏览器工具或读取设置 |
| `src/services/storage` | 可信上下文设置/密钥、本地 IndexedDB 文档与历史 | 文档缓存与历史可独立清理 |
| `src/ui` | 共享视觉变量、安全 Markdown、主题 | 原始 HTML 不渲染，KaTeX trust=false，链接协议白名单 |

## 文档与引用

`DocumentContext` 包含 URL 身份、内容版本哈希、标题、提取时间、片段、覆盖状态、警告与字符数。每个片段有 ID、标题路径、类型、次序与 `SourceLocator`。URL 普通标题锚点不分文档，`#/…` / `#!/…` SPA 路由保留。

正文根节点按语义容器与有效文字评分选择。排除导航、页脚、侧栏、隐藏节点、表单、可编辑区与常见聊天容器；代码保留换行，表格按行提取，链接保留地址。DOM 不包含足够语义块时对清理后的克隆使用 Readability 回退，并标注结构可能不完整。超过 500,000 字符仅提取上限内的内容，明确标注部分读取。

引用只接受本次来源集合中实际存在的 ID。定位先尝试 CSS 路径并校验文本，再用引用摘要和前后文寻找唯一匹配；结果有歧义则失败。高亮使用覆盖层，不重写原文样式或布局。模型为真实片段引用不等于模型推论必然正确，用户仍可查看片段核验。

## 上下文与生命周期

- 普通问题：检索相关块并补相邻块，原文预算默认 12,000 字符；有限历史预算默认 7,000 字符。选区额外上限 6,000 字符，周围内容有独立上限。界面明确字符预算不是精确 token 数。
- 全文概括：经设置或单次提示允许，遍历全部已提取块逐批摘要，笔记过长时分层压缩后汇总。不会只概括文档开头。用户可停止整个流程。
- 阅读模式：以标签页、规范化 URL 和当前 content script 生命周期随机标识保存在可信 session storage。后台休眠不丢失开关；跨页导航、刷新、关闭和数据清理时清除，持续站点授权不自动启用。
- 选区短解释：启用时先在页面本地缓存正文，后台按选区检索最多 6,000 字符的相关文档片段，并补充选区附近上下文；短请求 25 秒超时。关闭、换页或旧正文失效时取消请求，复杂长请求仅由用户主动进入侧边栏运行。
- 首次发送：小浮窗展示配置服务的 origin 及发送范围，点击确认后才发起模型请求。配置缺失时可以直接打开模型设置，普通网页不接收密钥。
- URL/正文变化：MutationObserver 防抖失效，正文签名覆盖全部当前 DOM 文字。SPA 导航读取新页；同 URL 正文更新停用旧上下文并提示主动重新读取，避免直播计数等动态文字引起循环解析。切换标签页/文档会取消旧请求，对异步结果做版本检查。
- 缓存：当前页内无变化复用解析结果；手动重新读取强制解析；IndexedDB 保存最近 30 份文档用于本地状态。不同内容版本默认创建对应新会话。

## 权限与数据

安装只声明 activeTab、scripting、sidePanel、storage、contextMenus。HTTP/HTTPS 网站访问是 optional host permission；仅按用户点击授予对应域名。模型服务授权与网页持续授权分别维护，模型接口域名不会自动注册为阅读站点。

空白处右键菜单、工具栏 `action.onClicked` 和快捷键均获得 `activeTab` 后切换当前页阅读模式；启用只读取文档、显示简短页内提示和 `ON` 标记，不打开侧边栏。单个普通右键菜单项动态显示“打开阅读助手 / 关闭阅读助手”。不启用 `openPanelOnActionClick` 自动切换模式。只有浮窗中的主动问答入口同步调用 `sidePanel.open`，以保留真实用户手势。`tabs.Tab.url` 缺失表示元数据尚未获准访问，不据此断定网页属于受限协议。

URL 元数据缺失时，以浏览器权限约束下的轻量脚本读取尝试确认权限状态；已知受限协议由浏览器拒绝原因识别，不扩大全局标签页权限。标签页导航同时监听加载状态，加载开始停用旧上下文，完成后重试尚未成功的读取，避免依赖被隐藏的 URL 更新事件。

`chrome.storage.local` 与 `chrome.storage.session` 都设为 `TRUSTED_CONTEXTS`。密钥可选本地/浏览器会话模式，网页脚本与 content script 不可读取。文档/历史在 IndexedDB。没有遥测、账号、同步和强制后端。

## 后续扩展点

新的 LLM 协议实现 `LLMProvider`；PDF 可生成相同文档片段并扩展页码定位器；多文档检索在现有片段上增加集合与来源范围。任何具有副作用的 Agent 行为应另行设计用户授权，不通过网页提示词开启。
