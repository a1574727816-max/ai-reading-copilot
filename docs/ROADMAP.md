# 后续开发路线

## V1.1

- 扩展内部 PDF.js 阅读界面：导入本地 PDF、文字与页码提取、选区解释、按页引用定位；扫描件 OCR 另立范围。
- 用户主动创建多页面文档集合，检索范围显式选择，引用标明网页与版本，不默认爬取整站。
- 补充宇树等动态站点的真实设备回归样本与定位规则。

## V1.5

- 术语收藏、来源上下文、笔记、标签、搜索与删除，默认不自动保存每次划词。
- 快速、通俗、技术深入与苏格拉底学习模式。
- 文档知识框架、概念依赖和建议阅读次序。
- 按模型、日期记录调用与真实 token；用户配置单价，估算费用明确标注，不冒充账单。

## V2.0

- 在用户授权的文档集合内规划并自主检索，证据不足时补读关联章节。
- 学习路径与可编辑的本地个人知识上下文。
- 默认关闭、由用户选择启用的前置知识提示。
- 使用明确配置的视觉模型分析架构图、图表与含图片 PDF；区分视觉理解和 DOM 提取结果。

这些能力沿现有文档、来源定位、检索与 Provider 接口扩展。账号、云端同步、自动浏览器操作等不随版本号默认引入。
