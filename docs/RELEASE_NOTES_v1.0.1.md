# AI Reading Copilot v1.0.1

修复 v1.0.0 中“点击工具栏总是提示页面受浏览器限制，划词后通过右键却能正常读取”的问题。

## 修复

- 工具栏改为正常的扩展动作入口，获得当前标签页的临时 `activeTab` 权限后显式打开侧边栏。
- 侧边栏已经打开并显示权限错误时，再次点击工具栏会重新读取当前页，不依赖界面重载或切换标签页。
- 区分“尚未获得网页读取权限”和真正的浏览器内部/商店等受限页面，避免将浏览器隐藏的 URL 元数据误判为不受支持的网页。
- 浏览器启动和扩展升级时恢复正确的工具栏行为；快捷键复用相同的打开与重读流程。
- 标签页加载时立即停用旧文档上下文；即使 URL 元数据被隐藏，也会在加载完成后更新读取状态，避免旧错误持续残留。
- 未增加 `tabs` 或强制全站读取权限，右键入口保持可用。

## 验证

- 在未授予任何网站权限的全新 Chromium 配置中，复现了旧版打开侧边栏但仍无法获得网页 URL 的问题。
- 使用 Linux X11 原生按键触发真实工具栏动作，验证当前页授权、已打开侧边栏恢复、另一未授权标签页恢复，以及没有新增持续网站授权。
- 24 项单元测试、原有 9 项端到端测试与新增 1 项真实工具栏权限测试通过。

Windows Chrome / Edge 的本机升级和系统交互仍需实际设备复核；权限修复已通过 Chromium 的真实浏览器动作验证。

## 更新方式

1. 下载附件 `ai-reading-copilot-1.0.1-extension.zip`。
2. 解压并覆盖原先安装扩展的文件夹，保持文件夹路径不变，无需卸载扩展。
3. 在 `chrome://extensions` 或 `edge://extensions` 点击此扩展的“重新加载”。
4. 刷新文档网页，点击工具栏中的阅读助手图标。

保持原目录可保留扩展身份与本地设置；会话密钥遵循原先的保存策略。安装包与源码包均不包含个人密钥。

完整使用说明：[README](https://github.com/a1574727816-max/ai-reading-copilot#readme)。
